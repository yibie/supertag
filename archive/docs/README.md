# Historical documentation

These files are kept for the record. They describe entry points and models that
are no longer current, so do not copy them as configuration.

- `legacy/` — guides for retired features and older UI models: the standalone
  capture engine, the field era, the old Table/Virtual-columns model, the
  plugin and view-framework guides from before the V2 reorganization, and the
  old/new architecture comparison.
- Field-era code lives in `../fields/`, the older ontology material in
  `../ontology/`.

Current documentation starts from the repository README and the files it links:
`doc/QUERY.md`, `doc/AUTOMATION-SYSTEM-GUIDE_cn.md`, `doc/SYNC-CONFIGURATION.md`,
`doc/MIGRATING-TO-SUPERTAG.md`, `doc/CUSTOMIZATION_CN.md`,
`doc/UNLINKED-MENTIONS.md`.

Task briefs and reports, plan notes and design records produced while working on
this repository are kept locally and are not shipped; that directory is listed
in the repository `.gitignore`.

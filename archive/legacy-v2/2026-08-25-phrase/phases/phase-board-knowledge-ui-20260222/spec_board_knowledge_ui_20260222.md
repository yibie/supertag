# spec_board_knowledge_ui_20260222

## Summary
将 `ext/board-ui` 从“通用白板”升级为面向 org-supertag 的“语义知识板”，核心目标是提升关系探索效率。

## Goals
- 在节点卡片中按标签展开显示字段和值（按 tag/schema 规则）。
- 支持卡片下拉展开查看完整笔记内容，内容区域有最大高度并可滚动。
- 支持 Group 视觉容器渲染与板内组织。
- Node Palette 的 tag 分组默认折叠，降低首屏视觉噪音。

## Non-goals
- 本阶段不实现 Group 的业务语义写回（仅视觉容器）。
- 本阶段不要求兼容性约束（按当前决策快速迭代）。
- 本阶段不包含右键菜单与自动化动作触发。

## User Flows
1. 字段预览：
   - 操作：用户点击卡片中的某个标签。
   - 反馈：该标签展开后显示其字段与字段值（按 tag/schema）。
   - 回退：字段缺失时显示空状态或占位，不阻断板操作。

2. 卡片内容展开：
   - 操作：用户点击卡片展开控件。
   - 反馈：展示完整笔记正文；超出上限高度时卡片内部滚动。
   - 回退：再次点击可折叠；刷新后默认折叠。

3. Group 组织：
   - 操作：用户在板内创建/使用 Group 容器整理节点。
   - 反馈：节点视觉上归属于 Group 区域。
   - 回退：可移出 Group，不影响节点语义数据。

4. Add Node 面板：
   - 操作：用户打开 Node Palette。
   - 反馈：所有 tag 分组默认折叠，按需展开添加节点。
   - 回退：无。

## Edge Cases
- 节点正文过长：必须限制渲染高度并使用滚动，避免画布被单卡片撑爆。
- 节点标签字段缺失或 schema 未命中：显示降级占位，不报错。
- Group 区域为空或节点频繁进出：UI 状态保持稳定，不影响移动和连线。

## Acceptance Criteria
- 用户可在 board 节点中点击标签并看到该标签下的字段和值。
- 用户可在卡片内展开查看完整笔记内容，且内容区有高度上限与滚动。
- Group 在画布中可见并可用于视觉组织节点。
- Node Palette 的 tag 分组初始状态为全部折叠。
- 主观验收目标：用户可在 2 分钟内整理完一个相关知识领域。
